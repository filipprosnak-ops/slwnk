# Cursor + MAHL Plugin Development Setup

This package contains all configuration and workflow documents needed to use Cursor AI efficiently
while building the MAHL Manager WordPress plugin.

The goal:
- predictable AI behavior
- minimal wasted prompts
- minimal token usage
- controlled code generation
- professional plugin architecture

These documents instruct Cursor how to behave, what architecture to follow,
and how tasks must be executed.

You should NOT start coding immediately.

First step is to upload all these files into the root of your project repository.
