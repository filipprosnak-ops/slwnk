# Project Overview

Plugin name: MAHL Manager

Purpose:
WordPress plugin for managing amateur hockey leagues.

Core entities:
- Seasons
- Teams
- Players
- Games
- Standings
- Player statistics

Principles:
- Automatic frontend pages (no shortcode dependency)
- WordPress native architecture
- Clean modular PHP structure
- Security-first implementation
- Maintainable long-term codebase

Version 1 scope:
- Season management
- Team management
- Player management
- Game management
- Standings calculation
- Player statistics
